## Routing / Source/Header Sync / C API Catch-up

- Core/Codec、Text/module、Ganesh/Graphite の tracked source/header を同期。三者比較は競合なし。
- `SkBigPicture` を upstream の `SkPicture` への統合に合わせて削除し CMake 明示 source list からも除去。
- `SkPicture_playback` / `SkPicture_cullRect` / `SkPicture_approximateOpCount` / `SkPicture_approximateBytesUsed` は pure virtual から concrete method への変更。C API は opaque picture pointer 経由で同じ入力/出力を保持する。C++ SkPicture subclass/layout の ABI は対象外で、C API の placeholder/recording/実オブジェクト操作を source/prebuilt focused smoke で確認。
- `SkShaper_shapeWithTextTracking` は upstream の SkSpan<const char>/SkSpan<const Feature>/SkShaper::Options overload に追従。既存 C ABI は不変。古い tracking overload の signature_changed_review はこの移行で解消。
- グローバル helper の新規 `SkWriteICCProfile(const SkColorSpace*, const skhdr::Metadata*)` を `SkICC_SkWriteICCProfileFromColorSpace` で公開。ColorSpace は必須、metadata は optional borrowed。成功時のデータは caller-owned handle。upstream のこの checkpoint は metadata をまだ使用しない。
- SkSafetyChecks/partition_alloc safety shim、Graphite end caps/wide tiles/alpha atlas/sparse strips helpers を同期。GPU source は既存 glob で取得。
- SkDeserialImageProc の C++ callback 型は optional alpha type 付きに統一された。既存 C API は SkDeserialProcs を opaque borrowed pointer として扱うため C 関数 signature は不変。C++ で callback struct を構築する利用者は新しい upstream 型を使用する必要がある。独自 callback bridge は追加しない。upstream の変更により fImageProc 未設定時には画像を decode しないことも記録し、画像を含む独自 deserialize では新しい callback 型が必要。
- optional backend/依存モード/ownership 方針は維持。GN/Bazel/infra/DEPS の dependency roll は同期対象外。
- focused smoke: ICC データの acsp signature、shaping tracking の実 glyph position、RuntimeShader bounds、picture recorder/placeholder 操作を source/prebuilt で検証。

- 初回 GPU build は disabled Sparse Strips の EndCap/WideTile RenderStep が glob に入って失敗。SK_ENABLE_SPARSE_STRIPS の Geometry variants が無効なので、既存 backend 方針に従い2ソースを CMake filter で除外して再 configure/build。Sparse Strips の有効化は行わない。
